# Eric Jay profile README — setup

This bundle is designed for the special GitHub profile repository:

    ericjaytech/ericjaytech

## Files

- `README.md` — profile content
- `assets/header.svg` — custom responsive header artwork
- `.github/workflows/snake.yml` — refreshes the contribution animation daily

## Install

1. Copy the files into the root of `ericjaytech/ericjaytech`.
2. Commit and push to the `main` branch.
3. Open the repository's **Actions** tab.
4. Run **Generate contribution animation** once manually.
5. The workflow creates an `output` branch containing the light/dark SVGs.
6. Refresh the public GitHub profile.

The action then refreshes automatically once per day.
